# 👁️ Third Eye

**Third Eye** is an AI-powered chatbot designed to help users **learn, create, explore, and interact with AI** through a simple and professional web interface.

## ✨ Features

* 🤖 AI-powered conversations
* 💬 Real-time AI responses
* 📄 File upload and document analysis
* 🖼️ Image upload and image analysis
* 📚 Definitions, meanings, synonyms and antonyms
* 🔊 Pronunciation assistance
* 🎤 Voice input
* 🌙 Dark mode
* 📜 Chat history
* 🧹 Clear chat and history controls
* 👤 User accounts with login and signup
* 📎 Multiple attachment support
* ❓ Built-in help section
* 🔔 Browser notifications when an answer is ready

## 🛠️ Technologies

### Backend

## 🔐 Security

API keys and other sensitive configuration values should be stored securely using environment variables.

Sensitive information such as API keys, passwords, and `.env` files should **never be committed to GitHub**.

## 🚀 Running the Project Locally

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Create a `.env` file and add the required API configuration.

### 3. Start the server

```bash
node server.js
```

The application can then be accessed through the configured local server.

## 💡 Purpose

Third Eye is built as a practical AI assistant that combines everyday conversation with useful tools such as file analysis, image understanding, voice input, history, and language assistance.
